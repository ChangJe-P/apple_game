# apple_game
사과 게임 만들기!

규칙.
드래그한 사각형 내의 사과의 합이 10이 되면 된다.
사과 개수는 17 * 10 개이다
점수는 제거한 사과의 수로 책정한다

1. 사과 띄우기
2. 드래그 이벤트 
3. 랜덤 숫자 셋팅
4. 숫자 합이 10이 되어야함. 
5. 합쳐진 사과는 사라짐.
6. 사라진 사과의 수는 점수가 된다.
7. 제한시간(2분30초)동안 게임이 진행된다.
8. 제한시간이 끝나면 최종 점수를 화면에 표시 
9. 게임이 끝나면 다시하기 버튼과 최고 점수 표시 
10. ai 가 이걸 풀어야함. -> 최종 목표
